# Input Files

This directory documents the local source files expected by the reproducible analysis workflow.

The public GitHub repository should contain the documentation files in this directory, but the underlying dissertation source documents and participant-level questionnaire dataset should not be published here.

## Expected local structure

```text
01_INPUTS/
├── 01_CHAPTERS_1_TO_3/
│   └── Chapters 1-3_030926.docx
├── 02_QUESTIONNAIRE_AND_CODEBOOK/
│   └── BEMM828_Questionnaire_Only_Qualtrics_Build.docx
└── 03_RAW_DATA/
    └── BEMM828_Questionnaire Data.xlsx
```

The files shown above are expected for full local reproduction of the original workflow. They are intentionally absent from the public repository.

See the README file inside each subdirectory for its purpose and publication boundary.
