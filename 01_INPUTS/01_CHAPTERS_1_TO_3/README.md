# Chapters 1 to 3 Source Document

The dissertation source document used during the original analysis workflow is not included in this public repository.

For full local reproduction, the preparation script expects:

```text
01_INPUTS/01_CHAPTERS_1_TO_3/Chapters 1-3_030926.docx
```

## Purpose in the workflow

`02_prepare_inputs.py` reads the Chapter 3 section from this document to preserve a compact record of the methodology and scoring provenance used by the analysis.

The dissertation document is not used as a substitute for the raw questionnaire data and does not generate empirical results.

## Public repository boundary

The dissertation source document should not be committed to the public repository. Keep this README file in the directory so that the expected local file path remains documented.
