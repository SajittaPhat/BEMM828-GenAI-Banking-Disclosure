# Questionnaire and Codebook

The full fielded questionnaire and codebook document are not included in this public repository.

For full local reproduction, the scripts expect:

```text
01_INPUTS/02_QUESTIONNAIRE_AND_CODEBOOK/BEMM828_Questionnaire_Only_Qualtrics_Build.docx
```

## Purpose in the workflow

The questionnaire/codebook source is used to verify:

- eligibility variable identifiers
- focal construct variable identifiers
- demographic/context variable identifiers
- questionnaire-to-workbook mapping
- measurement and scoring provenance

The analytical scripts contain the variable identifiers required for the statistical workflow, including the 27 focal indicators.

## Public repository boundary

The full questionnaire document should remain outside the public repository. This avoids publishing the complete fielded questionnaire and adapted measurement wording unnecessarily.

Keep this README file in the directory so that the expected local file path and purpose remain documented.
