# Analytical Outputs

The statistical scripts write generated analytical outputs to this directory during local execution.

Typical outputs include aggregate measurement diagnostics, construct descriptives, correlations, structural path results, bootstrap indirect effects, robustness results, sensitivity results, software-session information and the scoring lock.

## Participant-level outputs

Do not publish participant-level derived files in the public repository.

In particular, the following locally generated files should remain private:

```text
agent_2_locked_raw_fields.csv
agent_2_locked_scores.csv
```

## Aggregate outputs

Aggregate non-participant-level outputs may be retained locally or shared selectively where appropriate. The public repository does not require the complete output directory in order to document the analysis code.

Keeping this README file allows the directory structure expected by the scripts to remain clear without publishing research data.
